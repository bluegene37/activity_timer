# Pour-over Brew Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Brew tab to Activity Timer that runs pour-over recipes as timed steps, showing the cumulative water target for each pour and rescaling the whole recipe from coffee dose and brew ratio.

**Architecture:** Four new Hive models hold a recipe whose steps store pour targets as *fractions of total water*, so `dose × ratio` rescales everything by multiplication. A pure-Dart `BrewRecipe` owns all the math (no Flutter, no Hive access), a `BrewController` owns the list, and a `BrewRunController` owns the running clock behind an injected clock and cue player so timing is testable without real time or audio. Three screens sit under a `BrewTheme` that applies the genexis.dev washi palette to the Brew subtree only. Everything is additive: no existing model, box, screen, or route changes, except `MainNavigation` gaining a fourth tab.

**Tech Stack:** Flutter, GetX (state + routing), Hive CE (persistence, adapters generated by `hive_ce_generator` via `build_runner`), `audioplayers` (cues), `wakelock_plus` (screen awake), `flutter_test`.

**Spec:** `docs/superpowers/specs/2026-08-25-pour-over-brew-timer-design.md`

## Global Constraints

- Verification for every task: `flutter analyze && flutter test` must both pass. `flutter analyze` is not optional — `analysis_options.yaml` enables `strict-casts`, `strict-inference`, and `strict-raw-types`.
- House lints to write to, not fight: single quotes, `prefer_final_locals`, `always_declare_return_types`, `sort_constructors_first` (constructors go before fields), `unawaited_futures` (wrap fire-and-forget futures in `unawaited(...)` from `dart:async`), `use_super_parameters`, `directives_ordering` (dart: imports, then package:, then relative — each group alphabetical).
- Hive typeIds 0–7 are taken. This feature uses **exactly** 8 (`BrewRecipe`), 9 (`BrewStep`), 10 (`BrewStepKind`), 11 (`BrewMethod`). Never reuse or renumber.
- Generated `*.g.dart` files are excluded from analysis and must never be hand-edited. Regenerate with `dart run build_runner build --delete-conflicting-outputs`, which rewrites both `lib/models/*.g.dart` and `lib/hive_registrar.g.dart`.
- **Never push a named route with a concrete type argument.** GetX builds every named route as `GetPageRoute<dynamic>`, so `Get.toNamed<bool>(...)` throws `type 'GetPageRoute<dynamic>' is not a subtype of type 'Route<bool?>?'` inside `Navigator.pushNamed`. Always `Get.toNamed<dynamic>(...)` and narrow with `result == true`.
- The app is offline-only. No network calls, no `google_fonts`; fonts ship as bundled assets.
- Widget tests that touch Hive must open the boxes in `setUpAll` (see Task 2's test harness) — a `Hive.openBox` started inside the fake-async zone never completes and hangs the test.
- Tests that construct a screen playing audio must mock the `xyz.luan/audioplayers` and `xyz.luan/audioplayers.global` method channels; see `test/timer_screen_test.dart`.

```dart
import 'package:hive_ce/hive.dart';
import 'package:uuid/uuid.dart';

import 'alarm_sound.dart';

part 'brew_recipe.g.dart';

@HiveType(typeId: 10)
enum BrewStepKind {
  @HiveField(0)
  pour('Pour'),
  @HiveField(1)
  wait('Wait'),
  @HiveField(2)
  swirl('Swirl'),
  @HiveField(3)
  drawdown('Drawdown');

  const BrewStepKind(this.displayName);

  final String displayName;
}

@HiveType(typeId: 11)
enum BrewMethod {
  @HiveField(0)
  v60('V60'),
  @HiveField(1)
  chemex('Chemex'),
  @HiveField(2)
  kalita('Kalita Wave'),
  @HiveField(3)
  aeropress('AeroPress'),
  @HiveField(4)
  switchBrewer('Switch');

  const BrewMethod(this.displayName);

  final String displayName;

  /// Resolves a persisted [Enum.name], falling back to [BrewMethod.v60].
  static BrewMethod fromString(String? value) => BrewMethod.values.firstWhere(
    (method) => method.name == value,
    orElse: () => BrewMethod.v60,
  );
}

/// One timed step of a brew. A step with a [pourToFraction] is a pour: the
/// fraction is the cumulative share of the recipe's total water the scale
/// should read by the end of the pour window, so changing the dose rescales
/// every target at once.
@HiveType(typeId: 9)
class BrewStep extends HiveObject {
  BrewStep({
    required this.name,
    required this.seconds,
    this.kind = BrewStepKind.pour,
    this.pourToFraction,
    this.pourSeconds,
    this.description,
  });

  @HiveField(0)
  String name;

  @HiveField(1)
  int seconds;

  @HiveField(2)
  double? pourToFraction;

  @HiveField(3)
  int? pourSeconds;

  @HiveField(4)
  BrewStepKind kind;

  @HiveField(5)
  String? description;

  bool get isPour => pourToFraction != null;

  BrewStep copyWith({
    String? name,
    int? seconds,
    BrewStepKind? kind,
    double? pourToFraction,
    int? pourSeconds,
    String? description,
  }) => BrewStep(
    name: name ?? this.name,
    seconds: seconds ?? this.seconds,
    kind: kind ?? this.kind,
    pourToFraction: pourToFraction ?? this.pourToFraction,
    pourSeconds: pourSeconds ?? this.pourSeconds,
    description: description ?? this.description,
  );
}

@HiveType(typeId: 8)
class BrewRecipe extends HiveObject {
  BrewRecipe({
    String? id,
    required this.name,
    required this.method,
    required this.doseGrams,
    required this.ratio,
    required this.steps,
    this.notes,
    String? alarmSoundName,
    DateTime? createdAt,
    DateTime? updatedAt,
  }) : id = id ?? const Uuid().v4(),
       alarmSoundName = alarmSoundName ?? AlarmSound.bell.name,
       createdAt = createdAt ?? DateTime.now(),
       updatedAt = updatedAt ?? DateTime.now();

  @HiveField(0)
  final String id;

  @HiveField(1)
  String name;

  @HiveField(2)
  BrewMethod method;

  @HiveField(3)
  double doseGrams;

  @HiveField(4)
  double ratio;

  @HiveField(5)
  List<BrewStep> steps;

  @HiveField(6)
  String? notes;

  @HiveField(7)
  String alarmSoundName;

  @HiveField(8)
  DateTime createdAt;

  @HiveField(9)
  DateTime updatedAt;

  AlarmSound get alarmSound => AlarmSound.fromString(alarmSoundName);

  /// Water the recipe finishes on, in grams.
  double get totalWater => doseGrams * ratio;

  int get totalWaterGrams => totalWater.round();

  int get totalSeconds =>
      steps.fold(0, (total, step) => total + step.seconds);

  int get pourCount => steps.where((step) => step.isPour).length;

  /// Cumulative scale reading for the pour at [index], or null when that step
  /// pours nothing.
  int? targetGramsAt(int index) {
    final fraction = steps[index].pourToFraction;
    return fraction == null ? null : (fraction * totalWater).round();
  }

  /// Water this pour adds: its target minus the target of the pour before it.
  int? addedGramsAt(int index) {
    final target = targetGramsAt(index);
    if (target == null) return null;
    for (var i = index - 1; i >= 0; i--) {
      final earlier = targetGramsAt(i);
      if (earlier != null) return target - earlier;
    }
    return target;
  }

  /// Pour speed in grams per second, or null when the step has no pour window.
  double? pourRateAt(int index) {
    final added = addedGramsAt(index);
    final window = steps[index].pourSeconds;
    if (added == null || window == null || window <= 0) return null;
    return added / window;
  }

  /// Human-readable reasons this recipe cannot be saved. Empty means valid.
  List<String> validationErrors() {
    final errors = <String>[];
    if (name.trim().isEmpty) {
      errors.add('Name cannot be empty.');
    }
    if (doseGrams <= 0) {
      errors.add('Dose must be greater than 0g.');
    }
    if (ratio <= 0) {
      errors.add('Ratio must be greater than 0.');
    }
    if (steps.isEmpty) {
      errors.add('A brew needs at least one step.');
    }

    var previousFraction = 0.0;
    var sawPour = false;
    for (var i = 0; i < steps.length; i++) {
      final step = steps[i];
      final label = 'Step ${i + 1} (${step.name.trim()})';
      if (step.seconds <= 0) {
        errors.add('$label must be longer than 0s.');
      }
      final fraction = step.pourToFraction;
      if (fraction == null) {
        continue;
      }
      sawPour = true;
      if (fraction < previousFraction) {
        errors.add('$label pours to less water than the step before it.');
      }
      if (fraction > 1) {
        errors.add('$label pours past the total water.');
      }
      previousFraction = fraction;
      final window = step.pourSeconds;
      if (window == null || window <= 0) {
        errors.add('$label needs a pour time.');
      } else if (window > step.seconds) {
        errors.add('$label pours for longer than the step lasts.');
      }
    }
    if (sawPour && previousFraction != 1) {
      errors.add('The last pour must reach the full water total.');
    }
    return errors;
  }

  BrewRecipe copyWith({
    String? name,
    BrewMethod? method,
    double? doseGrams,
    double? ratio,
    List<BrewStep>? steps,
    String? notes,
    String? alarmSoundName,
  }) => BrewRecipe(
    id: id,
    name: name ?? this.name,
    method: method ?? this.method,
    doseGrams: doseGrams ?? this.doseGrams,
    ratio: ratio ?? this.ratio,
    steps: steps ?? this.steps,
    notes: notes ?? this.notes,
    alarmSoundName: alarmSoundName ?? this.alarmSoundName,
    createdAt: createdAt,
  );

  /// A deep copy with a fresh id, for cloning a library recipe into the
  /// user's own list.
  BrewRecipe cloneAsNew({String? name}) => BrewRecipe(
    name: name ?? this.name,
    method: method,
    doseGrams: doseGrams,
    ratio: ratio,
    steps: [for (final step in steps) step.copyWith()],
    notes: notes,
    alarmSoundName: alarmSoundName,
  );
}
```

```dart
import 'app_theme.dart';

/// Washi-paper palette taken from genexis.dev. Scoped to the Brew section:
/// nothing outside `lib/screens/brew_*` should read these.
class BrewPalette {
  const BrewPalette({
    required this.paper,
    required this.paperRaised,
    required this.paperDeep,
    required this.ink,
    required this.inkSoft,
    required this.lead,
    required this.hairline,
  });

  final Color paper;
  final Color paperRaised;
  final Color paperDeep;
  final Color ink;
  final Color inkSoft;
  final Color lead;
  final Color hairline;
}

abstract final class BrewTheme {
  static const _light = BrewPalette(
    paper: Color(0xFFF2EDE3),
    paperRaised: Color(0xFFFAF7F0),
    paperDeep: Color(0xFFE7E0D0),
    ink: Color(0xFF16161A),
    inkSoft: Color(0xFF5A564E),
    lead: Color(0xFFB4402C),
    hairline: Color(0x2E2B2B2E),
  );

  // The site is light-only; these are derived so the tab still works in the
  // app's dark mode. Lead is lifted for contrast against dark paper.
  static const _dark = BrewPalette(
    paper: Color(0xFF1B1815),
    paperRaised: Color(0xFF241F1B),
    paperDeep: Color(0xFF15120F),
    ink: Color(0xFFF2EDE3),
    inkSoft: Color(0xFFB8B0A2),
    lead: Color(0xFFD9614A),
    hairline: Color(0x33F2EDE3),
  );

  static const fontFamily = 'Literata';

  static BrewPalette paletteFor(Brightness brightness) =>
      brightness == Brightness.dark ? _dark : _light;

  static BrewPalette of(BuildContext context) =>
      paletteFor(Theme.of(context).brightness);

  /// A theme that keeps [AppTheme]'s radii and spacing so the Brew section
  /// shares the app's layout grammar while changing palette and type.
  static ThemeData themeFor(Brightness brightness) {
    final palette = paletteFor(brightness);
    final colorScheme = ColorScheme(
      brightness: brightness,
      primary: palette.lead,
      onPrimary: palette.paperRaised,
      secondary: palette.inkSoft,
      onSecondary: palette.paperRaised,
      surface: palette.paperRaised,
      onSurface: palette.ink,
      surfaceContainerHighest: palette.paperDeep,
      onSurfaceVariant: palette.inkSoft,
      outlineVariant: palette.hairline,
      error: palette.lead,
      onError: palette.paperRaised,
    );

    final base = ThemeData(
      brightness: brightness,
      colorScheme: colorScheme,
      fontFamily: fontFamily,
      scaffoldBackgroundColor: palette.paper,
      useMaterial3: true,
    );

    return base.copyWith(
      textTheme: base.textTheme.apply(
        fontFamily: fontFamily,
        bodyColor: palette.ink,
        displayColor: palette.ink,
      ),
      cardTheme: CardThemeData(
        color: palette.paperRaised,
        elevation: 0,
        shape: RoundedRectangleBorder(
          borderRadius: BorderRadius.circular(AppTheme.cardRadius),
          side: BorderSide(color: palette.hairline),
        ),
      ),
      dividerTheme: DividerThemeData(color: palette.hairline, thickness: 0.6),
      elevatedButtonTheme: ElevatedButtonThemeData(
        style: ElevatedButton.styleFrom(
          backgroundColor: palette.lead,
          foregroundColor: palette.paperRaised,
          elevation: AppTheme.buttonElevation,
          padding: AppTheme.buttonPadding,
          shape: RoundedRectangleBorder(
            borderRadius: BorderRadius.circular(AppTheme.borderRadius),
          ),
        ),
      ),
    );
  }
}
```

```dart
import 'package:get/get.dart';

import '../models/brew_recipe.dart';
import '../routes/app_routes.dart';
import '../services/database_service.dart';

class BrewController extends GetxController {
  final _databaseService = DatabaseService();

  final RxList<BrewRecipe> recipes = <BrewRecipe>[].obs;
  final RxBool isLoading = true.obs;

  /// The recipe a brand-new brew starts from: one bloom, one pour, a drawdown.
  static BrewRecipe starterRecipe() => BrewRecipe(
    name: 'New Brew',
    method: BrewMethod.v60,
    doseGrams: 18,
    ratio: 16,
    steps: [
      BrewStep(name: 'Bloom', seconds: 45, pourToFraction: 0.12, pourSeconds: 10),
      BrewStep(name: 'Main pour', seconds: 60, pourToFraction: 1, pourSeconds: 30),
      BrewStep(name: 'Drawdown', seconds: 60, kind: BrewStepKind.drawdown),
    ],
  );

  @override
  void onInit() {
    super.onInit();
    loadRecipes();
  }

  Future<void> loadRecipes() async {
    isLoading.value = true;
    try {
      final stored = await _databaseService.getAllBrewRecipes();
      stored.sort((a, b) => b.createdAt.compareTo(a.createdAt));
      recipes.assignAll(stored);
    } catch (e) {
      Get.snackbar('Error', 'Failed to load brews: $e');
    } finally {
      isLoading.value = false;
    }
  }

  Future<void> refreshRecipes() => loadRecipes();

  Future<void> addNewBrew() async {
    // GetX builds every named route as `GetPageRoute<dynamic>`, so pushing with

  }
```

```dart
import 'dart:async';

import 'package:get/get.dart';
import 'package:wakelock_plus/wakelock_plus.dart';

import '../models/brew_recipe.dart';
import '../services/brew_cue_player.dart';

/// Runs a brew on the clock. Steps advance strictly by time; inside a pour
/// step the controller also reports whether the pour window is still open, so
/// the screen can say POUR then WAIT.
class BrewRunController extends GetxController {
  BrewRunController({
    required this.recipe,
    BrewCuePlayer? cuePlayer,
    DateTime Function()? clock,
    this.tickInterval = const Duration(milliseconds: 200),
  }) : _cuePlayer = cuePlayer ?? AudioBrewCuePlayer(),
       _now = clock ?? DateTime.now;

  final BrewRecipe recipe;
  final Duration tickInterval;

  final BrewCuePlayer _cuePlayer;
  final DateTime Function() _now;

  final RxInt stepIndex = 0.obs;
  final RxInt elapsedInStepMs = 0.obs;
  final RxBool isRunning = false.obs;
  final RxBool isFinished = false.obs;

  Timer? _ticker;
  DateTime? _stepStartedAt;
  int _carriedMs = 0;

  BrewStep get currentStep => recipe.steps[stepIndex.value];

  int? get currentTarget => recipe.targetGramsAt(stepIndex.value);

  int? get currentAdded => recipe.addedGramsAt(stepIndex.value);

  double? get currentRate => recipe.pourRateAt(stepIndex.value);

  /// True while the pour window of the current step is still open.
  bool get isPouring {
    final window = currentStep.pourSeconds;
    if (window == null || !currentStep.isPour) {
      return false;
    }
    return elapsedInStepMs.value < window * 1000;
  }

  Duration get stepRemaining => Duration(
    milliseconds:
        (currentStep.seconds * 1000 - elapsedInStepMs.value).clamp(0, 1 << 30),
  );

  Duration get totalElapsed {
    var total = elapsedInStepMs.value;
    for (var i = 0; i < stepIndex.value; i++) {
      total += recipe.steps[i].seconds * 1000;
    }
    return Duration(milliseconds: total);
  }

  /// What the next step will ask for, e.g. 'pour to 320g' or 'Drawdown'.
  String? get nextStepLabel {
    final next = stepIndex.value + 1;
    if (next >= recipe.steps.length) {
      return null;
    }
    final target = recipe.targetGramsAt(next);
    return target == null ? recipe.steps[next].name : 'pour to ${target}g';
  }

  void start() {
    if (isFinished.value) {
      return;
    }
    _stepStartedAt = _now();
    _ticker?.cancel();
    _ticker = Timer.periodic(tickInterval, (_) => _tick());
    unawaited(WakelockPlus.enable());
    isRunning.value = true;
  }

  void pause() {
    _carriedMs = elapsedInStepMs.value;
    _stepStartedAt = null;
    _ticker?.cancel();
    _ticker = null;
    unawaited(WakelockPlus.disable());
    isRunning.value = false;
  }

  void reset() {
    _ticker?.cancel();
    _ticker = null;
    _stepStartedAt = null;
    _carriedMs = 0;
    stepIndex.value = 0;
    elapsedInStepMs.value = 0;
    isRunning.value = false;
    isFinished.value = false;
    unawaited(WakelockPlus.disable());
  }

  void _tick() {
    final startedAt = _stepStartedAt;
    if (startedAt == null) {
      return;
    }
    elapsedInStepMs.value =
        _carriedMs + _now().difference(startedAt).inMilliseconds;

    while (!isFinished.value &&
        elapsedInStepMs.value >= currentStep.seconds * 1000) {
      final overflowMs = elapsedInStepMs.value - currentStep.seconds * 1000;
      unawaited(_cuePlayer.playStepEnd(recipe.alarmSound));

      if (stepIndex.value == recipe.steps.length - 1) {
        _finish();
        return;
      }

      stepIndex.value += 1;
      _carriedMs = overflowMs;
      _stepStartedAt = _now();
      elapsedInStepMs.value = overflowMs;
    }
  }

  void _finish() {
    _ticker?.cancel();
    _ticker = null;
    _stepStartedAt = null;
    elapsedInStepMs.value = currentStep.seconds * 1000;
    isRunning.value = false;
    isFinished.value = true;
    unawaited(WakelockPlus.disable());
  }

  @override
  void onClose() {
    _ticker?.cancel();
    unawaited(_cuePlayer.dispose());
    unawaited(WakelockPlus.disable());
    super.onClose();
  }
}
```

```dart
class BrewEditScreen extends StatefulWidget {
  const BrewEditScreen({required this.recipe, required this.isNew, super.key});

  final BrewRecipe recipe;
  final bool isNew;

  @override
  State<BrewEditScreen> createState() => _BrewEditScreenState();
}

class _BrewEditScreenState extends State<BrewEditScreen> {
  final _database = DatabaseService();
  late final TextEditingController _nameField =
      TextEditingController(text: widget.recipe.name);
  late final TextEditingController _doseField =
      TextEditingController(text: widget.recipe.doseGrams.toStringAsFixed(0));
  late final TextEditingController _ratioField =
      TextEditingController(text: widget.recipe.ratio.toStringAsFixed(1));

  late BrewRecipe _draft = widget.recipe;
  List<String> _errors = const [];

  double get _totalWater => _draft.doseGrams * _draft.ratio;

  void _onDoseChanged(String value) {
    final dose = double.tryParse(value);
    if (dose == null || dose <= 0) {
      return;
    }
    setState(() {
      // Targets are fractions, so they follow the dose with no rewriting.
      _draft.doseGrams = dose;
    });
  }

  void _onRatioChanged(String value) {
    final ratio = double.tryParse(value);
    if (ratio == null || ratio <= 0) {
      return;
    }
    setState(() => _draft.ratio = ratio);
  }

  /// The editor speaks grams; storage speaks fractions.
  void _setStepTargetGrams(int index, int grams) {
    setState(() {
      _draft.steps[index].pourToFraction = grams / _totalWater;
    });
  }

  Future<void> _save() async {
    _draft.name = _nameField.text.trim();
    final errors = _draft.validationErrors();
    if (errors.isNotEmpty) {
      setState(() => _errors = errors);
      return;
    }

    if (widget.isNew) {
      await _database.createBrewRecipe(_draft);
    } else {
      await _database.updateBrewRecipe(_draft);
    }
    Get.back<bool>(result: true);
  }

  @override
  void dispose() {
    _nameField.dispose();
    _doseField.dispose();
    _ratioField.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final palette = BrewTheme.paletteFor(Theme.of(context).brightness);

    return Theme(
      data: BrewTheme.themeFor(Theme.of(context).brightness),
      child: Scaffold(
        backgroundColor: palette.paper,
        appBar: AppBar(
          backgroundColor: palette.paper,
          foregroundColor: palette.ink,
          elevation: 0,
          title: Text(widget.isNew ? 'New Brew' : 'Edit Brew'),
          actions: [
            TextButton(onPressed: _save, child: const Text('Save')),
          ],
        ),
        body: ListView(
          padding: const EdgeInsets.all(20),
          children: [
            TextField(
              key: const Key('brew-name-field'),
              controller: _nameField,
              decoration: const InputDecoration(labelText: 'Name'),
            ),
            const SizedBox(height: 16),
            Row(
              children: [
                Expanded(

                    controller: _doseField,
                    keyboardType: TextInputType.number,
                    onChanged: _onDoseChanged,
                    decoration: const InputDecoration(labelText: 'Dose (g)'),

                const SizedBox(width: 12),

                  child: TextField(
                    key: const Key('brew-ratio-field'),
                    controller: _ratioField,
                    keyboardType: TextInputType.number,
                    onChanged: _onRatioChanged,
                    decoration: const InputDecoration(labelText: 'Ratio (1:x)'),
                  ),
                ),
              ],
            ),
            const SizedBox(height: 12),
            Text(
              'Total water ${_totalWater.round()}g',
              style: TextStyle(color: palette.inkSoft),
            ),
            const SizedBox(height: 20),

              _StepRow(

                index: i,
                step: _draft.steps[i],
                targetGrams: _draft.targetGramsAt(i),
                palette: palette,
                onTargetChanged: (grams) => _setStepTargetGrams(i, grams),
                onChanged: () => setState(() {}),
                onDelete: () => setState(() => _draft.steps.removeAt(i)),

                  padding: const EdgeInsets.only(bottom: 6),
                  child: Text(error, style: TextStyle(color: palette.lead)),

            ],
          ],
        ),
```

```dart
class _StepRow extends StatelessWidget {
  const _StepRow({
    required this.index,
    required this.step,
    required this.targetGrams,
    required this.palette,
    required this.onTargetChanged,
    required this.onChanged,
    required this.onDelete,
    required this.onMoveUp,
    required this.onMoveDown,
    super.key,
  });

  final int index;
  final BrewStep step;
  final int? targetGrams;
  final BrewPalette palette;
  final ValueChanged<int?> onTargetChanged;
  final VoidCallback onChanged;
  final VoidCallback onDelete;
  final VoidCallback onMoveUp;
  final VoidCallback onMoveDown;

  @override
  Widget build(BuildContext context) => Card(
    margin: const EdgeInsets.only(bottom: 12),
    child: Padding(
      padding: const EdgeInsets.all(12),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            children: [
              Expanded(
                child: TextFormField(
                  key: Key('brew-step-$index-name'),
                  initialValue: step.name,
                  decoration: const InputDecoration(labelText: 'Step name'),
                  onChanged: (value) {
                    step.name = value;
                    onChanged();
                  },
                ),
              ),
              IconButton(
                icon: const Icon(Icons.arrow_upward),
                onPressed: onMoveUp,
              ),
              IconButton(
                icon: const Icon(Icons.arrow_downward),
                onPressed: onMoveDown,
              ),
              IconButton(
                icon: const Icon(Icons.delete_outline),
                color: palette.lead,
                onPressed: onDelete,
              ),
            ],
          ),
          Row(
            children: [
              Expanded(
                child: TextFormField(
                  key: Key('brew-step-$index-seconds'),
                  initialValue: step.seconds.toString(),
                  keyboardType: TextInputType.number,
                  decoration: const InputDecoration(labelText: 'Seconds'),
                  onChanged: (value) {
                    step.seconds = int.tryParse(value) ?? step.seconds;
                    onChanged();
                  },

              const SizedBox(width: 12),
              Expanded(

                    helperText: 'blank = no pour',

                  onChanged: (value) => onTargetChanged(int.tryParse(value)),
                ),
              ),
              const SizedBox(width: 12),
              Expanded(

                  initialValue: step.pourSeconds?.toString() ?? '',

                  decoration: const InputDecoration(labelText: 'Pour secs'),
                  onChanged: (value) {
                    step.pourSeconds = int.tryParse(value);
                    onChanged();

            key: Key('brew-step-$index-description'),
            initialValue: step.description ?? '',
            decoration: const InputDecoration(labelText: 'Note (optional)'),
            onChanged: (value) {
              step.description = value.trim().isEmpty ? null : value;
              onChanged();
            },
          ),
        ],
```
